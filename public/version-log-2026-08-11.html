Admin console redesign & polish batch

2026-08-11 · backend repo v0-tega-transit-app · deployed on Render — tega-transit-api.onrender.com

This batch is all console and design-token work: the admin dashboard got a real identity system, two themes, breadcrumbs, a settings panel, a new icon set, and a softened corner scale. No public API contract changed — every endpoint, cache header, rate limit, and SSE behavior from the 08-09 scaling batch is untouched. One database migration needs to run, and the frontend should pick up the new design tokens to stay in sync.

ACTION REQUIREDRun migration 0015

Open Supabase → SQL Editor and run supabase/migrations/0015_admin_profile.sql. It adds a display_name column to admin_emails so the console's new Settings → Profile card can persist a display name. Until it runs, saving a name reports a graceful "could not reach the database" error instead of crashing — the rest of the console works fine.

What shipped

CONSOLEIdentity & settings

Sidebar footer now shows who's signed in — avatar initial, email, and an Admin / Curator badge — above Log out. New Settings tab: a Profile card (change display name, shows in the sidebar instead of the raw email; read-only email, role, member-since) and an Appearance card (theme choice, synced with the header toggle). Breadcrumbs (Console / Map & Stops) follow every section.

CONSOLETwo themes — dark + ivory

Warm charcoal dark is the default; an ivory light mode is one click away. Until you choose, the console follows your OS preference (prefers-color-scheme) live. Choice persists in localStorage under busgo-admin-theme; the login page reads the same key, so the front door always matches.

CONSOLEPortal theme fix

Dropdowns, menus, selects, and dialogs render on document.body, outside the theme wrapper — they used to flash white in dark mode. The theme class is now mirrored onto <html>, so every overlay inherits the console tokens in both themes.

SHAREDPhosphor icons NEW

Every icon in the console, login page, status page, and the shadcn primitives moved from Lucide to @phosphor-icons/react at a consistent regular weight. lucide-react is gone from dependencies. Frontend: adopt Phosphor so both apps speak the same visual language.

SHAREDSofter radius scale

The base radius token moved 0.625rem → 0.75rem: controls 8→9.6px, cards 14→16.8px. One token drives the whole scale, so badges, buttons, inputs, and panels stay in the same corner family (toward a squircle feel).

CONSOLEChrome cleanup

Solid sticky header (was transparent), uniform 32px header controls, border-radius normalized (badges match buttons), width-capped forms so inputs don't stretch on ultrawide, per-panel stat cards, and the header's utility actions (Copy guide, Debug mode) consolidated into a kebab menu.

CONSOLESidebar structure

Nav grouped: Overview → Map data → System → Administration (admin settings last, as admins expect). Footer reads Links → Account → Log out. The brand lockup is a static block — no button hover or focus ring. Active section wears a teal tint.

AUTHRole hardening

An admin row with a NULL role (seeded before migration 0014) now counts as admin instead of silently hiding the admin-only sidebar links. If the console ever looks short of links, check the identity badge first.

For frontend developers

FRONTEND 1. Nothing changed in the API

All endpoints, query params, headers, cache semantics, and the SSE contract are identical to the 08-09 batch. If your app was working against https://tega-transit-api.onrender.com/api, it keeps working — no code changes needed. The only public-visible difference is cosmetic: the status page now uses the same Phosphor icons and corner radii as the console.

FRONTEND 3. Console login & theme notes

  • Admin sign-in is /goToAdminAuth — the OTP email and magic link point at the Render URL (ADMIN_PUBLIC_URL), never localhost.
  • A light-mode OS now lands on the ivory theme automatically at /admin and /goToAdminAuth unless the user has toggled.
  • The session still expires after 15 idle minutes (8h cap) — the login page shows a live countdown.
